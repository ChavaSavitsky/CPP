# C++ Programming Portfolio

A collection of C++ assignments and practice exercises completed as part
of my Software Practical Engineer studies.

The repository highlights selected exercises covering core C++ concepts,
object-oriented programming, memory management, data structures, and
testing.

## Selected Topics

-   **Custom String Class (`MyString`)** --- custom string handling,
    constructors, copy and move operations, and operator overloading.
-   **Linked List (`PList`)** --- linked-list implementation, iterators,
    smart pointers, and unit tests.
-   **Histogram** --- grouping values into ranges and testing expected
    behavior and edge cases.

## Repository Structure

Each project is organized in its own directory and contains the relevant
source files and, where applicable, tests.

## Building and Running

Build and run each exercise using the compiler or IDE configuration
appropriate for that exercise. Some exercises may require their original
project setup or test dependencies.

## About

These projects represent academic practice and demonstrate my ongoing
development of C++ programming skills.
